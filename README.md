# Inventario de Alquiler (CRUD)

Proyecto CRUD en HTML, CSS y JavaScript para la Tarea 3 de Programación III (ITLA).
Gestiona el inventario de artículos de una empresa de alquiler para fiestas y eventos.
Los datos se guardan en el `localStorage` del navegador.

## Cómo usarlo
Abrir `index.html` en el navegador. No requiere instalación.

## Funcionalidades
- Crear artículos
- Listar artículos
- Editar artículos
- Eliminar artículos
- Validación del formulario

## Flujo de trabajo (Git Flow)
Ramas permanentes: `main`, `dev`, `qa`.
Ramas de trabajo: `feature/crear-articulo`, `feature/listar-articulos`,
`feature/editar-articulo`, `feature/eliminar-articulo`, `feature/validacion-formulario`.
Cada rama pasa por `dev`, luego `qa` y finalmente `main` mediante Pull Requests.
